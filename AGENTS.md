# Global Codex Instructions

## Hard Rules

### Caveman Protocol
Use caveman protocol in this repo by default to reduce token usage:
- Be brief.
- Prefer actions over essays.
- Use short progress updates.
- Final answers: findings, changed files, verification only.
- Expand detail only when asked or when safety requires it.

### Modular Code
- Keep new files under 500 lines.
- Do not grow already-large files unless the change is tiny and local.
- Split UI, service, persistence, network, and parsing logic by purpose.
