## 2024-11-09 - String Similarity Optimization
**Learning:** Calling `.split('')` on a Dart string splits it into a list of individual UTF-16 code units, which is functionally equivalent to iterating through the string using `.codeUnitAt(index)`. Neither method correctly handles multi-code-unit grapheme clusters (like emojis), but `split('')` incurs significant performance penalties by allocating an entirely new List containing single-character Strings for every single code unit in the original string.
**Action:** When comparing or iterating over strings at the character level, avoid `.split('')`. Use `.codeUnitAt(index)` to iterate directly over the unboxed integers, which dramatically improves execution time and avoids massive garbage collection spikes, while maintaining the exact same functional behavior (including the same UTF-16 surrogate pair edge cases).
